# Data Types
The data is stored in a server's hard disk

Servers are powerful computers that store information and perform services via requests made over a network.
- They can handle a large number of data requests simultaneously, making them ideal for collaboration

When creating a table, we name each field and decide what type of data will be stored in it.

The data type depends on the information stored in the fueld such as numbers, text, or dates. We also have to consider the type of operations we want to apply to that information


!["Patrons Table"](<patrons_table.png>)

A "string" is a sequence of characters such as letters, numbers, or punctuation.

In the patrons table, the name field is made up of strings, such as "Maham" and "James"

SQL has different data types that can hold strings
- VARCHAR data type is commonly used due to its flexibility to store snall or large strings 

Integer data types store whole numbers>
- INT can store numbers from less than negative two billion to positive two billion, such as the card_num field in teh patrons table
- FLOATS are numbers that include a fractional part or a decimal point, such as the total_fine field in the patrons table
