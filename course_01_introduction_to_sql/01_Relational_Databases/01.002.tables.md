# Tables

## Table Naming
- Clear
- Refer to the data
- Lowercase
- Underscores

## Datbases
- Rows are usually referred to as records
- Columns are usually referred to as fields

### Records
Each record contains the data for an individual observation


!["Patrons Table"](<patrons_table.png>)

Here in the patrons table, there are 4 records, one for each patron

The record for Jasmin indicates that she became a member in 2022 and currently owes $2.05 in fines

### Fields
Fields contain one piece of information for every record in a table.


!["Patrons Table"](<patrons_table.png>)

The names field in the patrons table contains all library patrons' names

#### Field naming
Field naming is important becuase field names must be typed out when querying a database with SQL
- Field names should be:
    - Lowercase
    - Use underscores
    - Singular
    - Different to the table and other fields


## Tables
Tables include a special field containing a unique identifier for each record, sometimes called a key
- The key value must be unique for each record

Using several big organized tables is usually better than having one big table for everything.

By keeping data in separate, related tables and connecting them with SQL, we can analyze and answer questions more easily than we could with spreadsheets
